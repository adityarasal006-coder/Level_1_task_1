# Level 1 - Task 1: Basic Webpage, Navigation Menu & Form

This repository contains the solution for **Level 1 - Task 1** of the Web Development Internship.

## Project Features

- **Semantic HTML5 & Modern CSS3**: Pure HTML and CSS without external frameworks.
- **Sticky Navigation Bar**: Includes links (Home, About, Contact) that smoothly scroll to sections on the page.
- **Hero Section**: Features an engaging headline, introductory paragraph, and styled responsive image.
- **Features Grid**: 3-card layout highlighting HTML structure, CSS styling, and responsive design fundamentals.
- **Contact Form**: Simple form with text input field, submit button, HTML5 validation, and styled submission response.

## Files

- index.html - Webpage structure and content
- style.css - Custom styling, layout, typography, and responsive adjustments
